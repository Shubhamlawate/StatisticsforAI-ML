 # Statistics for Machine Learning and Data Science Lab

This repository contains my **Python/Jupyter Notebook practicals** for the Statistics for Machine Learning and Data Science Lab.

## 📚 Practicals

The repository includes different experiments using Python, Pandas, NumPy, SciPy, and other libraries.

Each `.ipynb` file contains:

* Aim
* Procedure
* Python code
* Output
* Results/Conclusion

## 🛠️ Requirements

Install the required libraries:

```bash
pip install numpy pandas scipy matplotlib seaborn scikit-learn
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project in **Jupyter Notebook** or **VS Code**.
3. Open any `.ipynb` file.
4. Run the cells one by one.

You can also open the notebooks directly on GitHub to view the code and outputs.
